# 결정 기록

목표는 나중에 사용자가 「이걸 왜 했지 · 얼마로 했지」를 이 노트 하나로 되살리는 것이다. 한 일 목록이 아니라 **판단**을 남긴다.

## 쓰는 법

저장은 변경을 실제로 반영하고 확인한 **뒤**에 한다. 반영하지 못하고 끝나면 「무엇을」 첫 줄을 `- 미반영: <이유>` 로 쓰고, 반영되면 같은 제목으로 다시 저장해 고친다.

본문을 아래 꼴로 채워 stdin 으로 넘긴다. 제목은 무엇을 정했는지 짧게(예: 「실시간 갱신 주기 10초」). 스크립트는 이 스킬을 불렀을 때 보이는 Base directory 에서 두 단계 위 `scripts/save.mjs` 다.

```
node "<Base directory>/../../scripts/save.mjs" --title "제목" <<'EOF'
## 무엇을
- 바꾼 것 한두 줄

## 왜
- 계기: 누가 · 무슨 문제로
- 목표: 무엇이 좋아지길 바라나

## 어떻게 · 얼마로
- 적용한 값 · 기준 · 식: 숫자는 단위까지
- 범위 · 시작 시점:

## 버린 안
| 안 | 버린 이유 |
|---|---|
| | |

## 근거
- 커밋 · PR · 파일 경로 · 조회 결과 · 대화에서 사용자가 한 말

## 다시 볼 때
- 이 값이 바뀌면 같이 바꿀 것 · 확인할 것
EOF
```

스크립트가 `결정/<날짜> <제목>.md` 를 쓰고 `일지/<날짜>.md` 「오늘 내린 결정」에 링크를 건 뒤 그 두 파일만 커밋 · push 한다. 결과 세 줄(노트 · 일지 · push)을 최종 보고에 한 줄로 옮긴다.

## 칸 채우는 기준

| 칸 | 채우는 것 |
|---|---|
| 왜 | 사용자가 답한 목적. 답이 없었으면 「답 없음」, 짐작으로 채우지 않는다 |
| 어떻게 · 얼마로 | 실제로 적용한 값. 「조정함」 대신 「30초 → 10초」 |
| 버린 안 | 대화에서 실제로 나온 안만. 없으면 칸을 지운다 |
| 근거 | 다시 찾아갈 수 있는 것(커밋 해시 · PR 번호 · 경로) |

같은 날 같은 작업의 값이 바뀌면 같은 제목으로 다시 저장해 노트를 고친다. 다른 작업이면 새 노트.

## 넣지 않는 것

볼트는 개인 GitHub 비공개 저장소로 올라간다. 고객 개인정보(이름 · 전화 · 주소 · 계약자 정보)와 비밀값(토큰 · 비밀번호 · 키)은 쓰지 않는다. 필요하면 「고객 1건」 · 계약번호 끝 4자리처럼 줄여 쓴다.

## 지난 결정 찾기

`<볼트>/결정/` 을 제목 · 본문으로 grep 한다. 볼트 위치는 `OBSIDIAN_VAULT`, 없으면 `문서\ObsidianVault`.
